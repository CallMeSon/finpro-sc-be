## 5. Deskripsi Tugas

Pada Final Project ini, membangun sebuah aplikasi server REST API yang utuh dan berfungsi penuh menggunakan Node.js dan framework ExpressJS, serta terhubung langsung ke database MongoDB. Proyek ini menggabungkan seluruh materi yang telah dipelajari selama kelas.

## 6. Ketentuan Tugas

### a. Ketentuan Aplikasi yang wajib dikerjakan :

- **Bebas Memilih Tema Data:** Kamu bebas menentukan topik data aplikasi (bisa juga menggunakan tema dari tugas 1)
- **CRUD REST API:** Menyediakan **minimal 4 endpoint CRUD**: Create (POST), Read (GET), Update (PUT/PATCH), Delete (DELETE)
- **Struktur Folder Modular:** Memisahkan kode program ke dalam beberapa folder: config, models, controllers, routes, index.js/app.js.
- **Asynchronous & HTTP Status Code:** Gunakan async/await dan HTTP Status Code (200, 201, 404, 500)
- **Penyimpanan Database:** Data harus tersimpan secara permanen di database MongoDB

### b. Persyaratan wajib Github:

- Proyek harus diunggah ke GitHub
- Pastikan repository bersifat **Public**
- File **README.md** yang berisi panduan singkat cara menjalankan aplikasi dan daftar endpoint API yang tersedia

### c. Test Endpoint API:

- Melakukan testing endpoint api menggunakan **POSTMAN**

### d. Template PPT Presentasi saat final project:

- Judul Aplikasi, Nama mentee
- Arsitektur Aplikasi
- Cantumkan link GitHub
- METHOD yang digunakan (GET, POST, PUT, DELETE, dst)
